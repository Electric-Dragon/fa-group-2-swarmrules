# Ferienakademie 2026 — Active Matter & Brownian Dynamics Simulator

A 2D simulation framework for overdamped Langevin / Brownian dynamics of interacting agents navigating complex environments (mazes, open obstacle fields, and organic hybrid maps).

## ⚙️ Physics & Dynamics

The simulation numerically integrates 2D **overdamped Langevin dynamics** with discrete time step $\Delta t$:

1. **Total Force & Deterministic Drift**:
   $$\mathbf{F}_i = \mathbf{F}_{\text{propulsion}, i} + \sum_{k} \mathbf{F}_{\text{object} \to i} + \sum_{j \ne i} \mathbf{F}_{j \to i}$$
   $$\Delta \mathbf{r}_{\text{drift}} = \mathbf{F}_i \Delta t$$

2. **Translational Diffusion (Wiener Process)**:
   $$\Delta \mathbf{r}_{\text{diff}} = \sqrt{2 D \Delta t} \cdot \boldsymbol{\xi}, \quad \boldsymbol{\xi} \sim \mathcal{N}(0, \mathbf{I})$$
   where $D = \text{agent.diff}$.

3. **Rotational Diffusion**:
   $$\Delta \theta = \sqrt{2 D_r \Delta t} \cdot \eta, \quad \eta \sim \mathcal{N}(0, 1)$$
   where $D_r = \text{agent.rotdiff}$.

4. **Wall Collisions**: Position updates $\mathbf{r}_{\text{proposed}} = \mathbf{r} + \Delta \mathbf{r}_{\text{drift}} + \Delta \mathbf{r}_{\text{diff}}$ are checked against grid walls, sliding along open axes if an obstacle is hit.

## 🪝 Extension Hooks for Agent Behaviors

To implement custom agent behaviors, subclass `BaseAgent` (`src/entities/agent.py`) and override the following hooks:

### 1. `compute_self_propulsion(self) -> np.ndarray`
Defines an active propulsion force or steering vector $[F_x, F_y]$ generated by the agent itself.
- **Active Brownian Particle (ABP)** example:
  ```python
  def compute_self_propulsion(self) -> np.ndarray:
      speed = 2.0
      return speed * np.array([np.cos(self.theta), np.sin(self.theta)])
  ```

### 2. `update_internal_state(self, dt: float) -> None`
Called every time step after positions are resolved. Use this for internal state machines, energy depletion, sensory updates, or timers:
```python
def update_internal_state(self, dt: float) -> None:
    self.energy -= 0.05 * dt
    if self.energy <= 0.0:
        self.state = "inactive"
```

### 3. `force_on(self, other: BaseObject) -> np.ndarray`
Inherited from `BaseObject`. Computes the force vector $[F_x, F_y]$ that this agent exerts on `other`.
- **Soft-core repulsion** example (preventing overlap between agents):
  ```python
  def force_on(self, other: BaseObject) -> np.ndarray:
      diff = other.position - self.position
      dist = np.linalg.norm(diff)
      min_dist = self.radius + other.radius
      if 0 < dist < min_dist:
          direction = diff / dist
          overlap = min_dist - dist
          k = 50.0  # Spring stiffness
          return k * overlap * direction
      return np.zeros(2)
  ```

## 🚀 Minimal Example / Quickstart

```python
import numpy as np
from src.environment import GridEnvironment
from src.simulation import Simulation
from src.entities.agent import BaseAgent
from src.visualization import SimulationVisualizer


class ActiveAgent(BaseAgent):
    def __init__(self, agent_id: int, position: np.ndarray, speed: float = 2.5, **kwargs):
        super().__init__(agent_id=agent_id, position=position, **kwargs)
        self.speed = speed

    def compute_self_propulsion(self) -> np.ndarray:
        return self.speed * np.array([np.cos(self.theta), np.sin(self.theta)])


# 1. Environment
env = GridEnvironment(width=25, height=25)
env.generate_hybrid_environment(maze_threshold=0.5, field_obstacle_density=0.1, seed=42)

# 2. Simulation
sim = Simulation(env=env, dt=0.05, seed=42)
for i in range(15):
    pos = np.array([12.0 + np.random.uniform(-2, 2), 12.0 + np.random.uniform(-2, 2)])
    sim.add_agent(ActiveAgent(agent_id=i, position=pos, diff=0.1, rotdiff=0.4, speed=3.0))

# 3. Visualization
vis = SimulationVisualizer(sim)
vis.run(steps=500, interval=30)
```
